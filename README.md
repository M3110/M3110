# Olá! Eu sou o Bruno Silveira 👋

Sou um Engenheiro de Software Sênior na Stone e Engenheiro Mecânico, focado em resolver problemas analíticos complexos e em arquitetar sistemas financeiros de alta disponibilidade[cite: 1]. ## 🚀 O que eu construo

*   **Engenharia de Software em Larga Escala:** Atuo no domínio de Clearing da Stone, coliderando o design arquitetural para unificar aplicações de múltiplas redes de cartões (Visa, Amex, Master, Elo) em um ambiente verdadeiramente multi-tenant[cite: 1].
*   **Pesquisa Biomecânica & Modelagem Numérica:** Conduzo pesquisas em nível de mestrado no CEFET/RJ, desenvolvendo Web APIs em C# orientadas por Domain-Driven Design (DDD) e padrões estruturais (Factory, Facade, Repository) para simular o comportamento viscoelástico de ligamentos[cite: 1].
*   **Desenvolvimento de Produtos Extensíveis:** Desenvolvo plataformas de negócios full-stack e arquiteturas White-Label para aplicativos móveis voltados a exames de certificação, garantindo que o mesmo código base possa atender diferentes contextos, como OAB e CFC.

## 📈 Filosofia de Engenharia e Conquistas

Acredito na entrega de software resiliente, escalável e centrado na experiência de quem o utiliza. Em meu dia a dia, busco:
*   **Otimização de Performance:** Refatoração de modelos de banco de dados, migrando chaves primárias de UUID ou TEXT para tipos auto-incrementais como BIGINT ou BIGSERIAL para ganho drástico de performance, além de otimizar conexões PostgreSQL para suportar processamentos de até 70k RPM[cite: 1].
*   **Design Centrado no Usuário:** Refinamento contínuo da experiência de uso, como a remoção de telas de confirmação redundantes em fluxos mobile para tornar a jornada mais direta e fluida.
*   **Gestão de Riscos e Mentoria:** Atuação como ponto crítico de escalonamento em rotações 24/7, garantindo a estabilidade de sistemas que processam altos volumes financeiros, e atuando como mentor técnico para o time[cite: 1].
